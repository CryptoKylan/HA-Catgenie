# Resume cleaning

Resume is the state 3 half of the pause and resume pair. The contract for both buttons is [pause and resume](pause-resume-control.md).

Resume still posts literal state 3 through the existing operation writer. It is enabled by default for a new registration and requires an explicit online report. An existing registry choice is not changed. It is not start, stop, abort, or a special cycle. Normal-cycle firmware acceptance was owner-verified. Fault resume and cartridge allowance effects are not proven. It does not recover a water-fill fault or restore cartridge allowance.
